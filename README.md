# Tinta engine

## Italiano

Motore dei temi di **Tinta – Code Themes**: un plugin per Claude Code che legge il tema attivo e ridisegna la conversazione nel tab Code. I temi si scelgono e si gestiscono nell'app Tinta, da una galleria che continua a crescere; questo repository contiene solo il motore, con il tema gratuito Salvia.

Progetto indipendente, non affiliato ad Anthropic.

Licenza: tutti i diritti riservati. Nessuna licenza open source e' concessa.

## English

Theme engine for **Tinta – Code Themes**: a Claude Code plugin that reads the active theme and redraws the conversation in the Code tab. Themes are chosen and managed in the Tinta app, from a gallery that keeps growing; this repository contains only the engine, with the free Salvia theme.

Independent project, not affiliated with Anthropic.
